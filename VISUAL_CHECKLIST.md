# AI Advanced Roadmap - Quick Visual Checklist

## 🎯 What to Look For

### Before Generating (Empty State)
```
✓ Title says "Your Personalized AI Learning Roadmap"
✓ Badge shows "Smart Planner"
✓ Two intro cards visible (Why This Matters + How to Use)
✓ Empty state with 📋 icon and instructions
✓ All form fields have help text below them
✓ Track chips show icons + labels + descriptions
✓ Primary button has ✨ icon and gradient
```

### Form Fields Check
```
✓ Preparation Duration - has help text "Recommended: 3-6 months..."
✓ Weekly Intensity - options show "Part-time", "Balanced", "Full-time"
✓ Study Days Per Week - options describe schedule types
✓ Company Focus Mode - explains what each mode focuses on
✓ Daily Study Block - provides time management guidance
✓ Advanced Options checkbox reveals extra fields
```

### Track Chips Visual
```
🧠 DSA - "Core coding interviews"
⚡ Aptitude - "Quantitative & logical"
🗄️ SQL - "Database queries"
🏗️ System Design - "Architecture & scaling"

✓ Hover effect works (border changes, slight lift)
✓ Active state shows glow and background tint
✓ Icons are visible and clear
```

### After Clicking "Generate My Roadmap"
```
✓ Success alert appears with summary
✓ Alert shows duration, tracks, daily commitment
✓ Alert includes actionable tips
✓ Roadmap renders in the output area
```

### Generated Roadmap Check
```
✓ Each week has track emoji (🧠/⚡/🗄️/🏗️)
✓ Dates formatted as "Jan 15" (not ISO format)
✓ Arrow symbol (→) between dates
✓ "Topics:" label before topic list
✓ Confidence badge with tooltip on hover
✓ Daily tasks have checkboxes
✓ Completed tasks show strikethrough
✓ Smooth scrolling through weeks
```

### Validation Messages
```
Test with 1 month duration:
✓ Warning about short timeline

Test with 18 months duration:
✓ Tip about breaking into phases

Test with past interview date:
✓ Warning about invalid date

Test with no tracks selected:
✓ Alert to select at least one track
```

### Export Buttons
```
✓ "Export to Calendar (.ics)" - downloads file
✓ "Export Google CSV" - downloads CSV
✓ "Export Plan (JSON)" - downloads JSON
✓ "Print Roadmap" - opens print dialog
✓ "Auto-reschedule Missed Tasks" - works
✓ "Send to AI Mentor" - triggers action
```

### Mobile View (< 768px)
```
✓ Intro cards stack vertically
✓ Form fields in single column
✓ Track chips full width
✓ Buttons stack vertically
✓ Button text centered
✓ No horizontal scroll
✓ Touch targets large enough
```

### Dark Mode
```
✓ Background colors adapt
✓ Text remains readable
✓ Borders visible but subtle
✓ Cards have proper contrast
✓ Buttons maintain visibility
✓ No harsh color clashes
```

### Interactive Elements
```
✓ Checkboxes toggle on/off
✓ Track chips toggle selection
✓ Advanced options toggle fields
✓ Buttons have hover effects
✓ Smooth transitions everywhere
✓ No lag or jank
```

## 🐛 Common Issues to Watch For

### Layout Problems
- [ ] Overlapping elements
- [ ] Text cut off
- [ ] Buttons too small
- [ ] Poor spacing
- [ ] Misaligned items

### Visual Glitches
- [ ] Missing icons
- [ ] Wrong colors
- [ ] Broken gradients
- [ ] Invisible text
- [ ] Clashing themes

### Functional Issues
- [ ] Buttons don't click
- [ ] Checkboxes don't toggle
- [ ] Exports fail
- [ ] Validation missing
- [ ] Alerts don't show

### Content Problems
- [ ] Typos in text
- [ ] Unclear labels
- [ ] Missing help text
- [ ] Confusing messages
- [ ] Inconsistent tone

## ✅ Final Verification

Before marking as complete:

1. **Navigate to page** - Does it load without errors?
2. **Check empty state** - Is it helpful and clear?
3. **Fill form** - Are all fields intuitive?
4. **Generate roadmap** - Does it work smoothly?
5. **Review output** - Is it well-formatted?
6. **Test interactions** - Do all features work?
7. **Try exports** - Do files download correctly?
8. **Check mobile** - Is it responsive?
9. **Toggle dark mode** - Does theme work?
10. **Validate inputs** - Are warnings helpful?
