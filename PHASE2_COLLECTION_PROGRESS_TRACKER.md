## Troubleshooting

### Common Issues & Solutions

**Issue: Can't decide difficulty level**
- Easy: Simple loops, basic hash map, straightforward logic
- Medium: Requires some optimization or data structure choice
- Hard: Complex algorithms, multiple steps, heavy optimization needed

**Issue: Problem title seems generic**
- Solution: Be specific - "Maximum Subarray Sum" not "Find Maximum"
- Check against existing 22 problems to ensure uniqueness

**Issue: Not sure about company names**
- Reference: Check COMPANY_INTERVIEW folder for verified company lists
- Use: Top companies from collection sources

**Issue: Starter code validation failing**
- Python: Ensure proper indentation, type hints with list[int] syntax
- JavaScript: Check semicolons, arrow function syntax
- C++: Verify vector<int> syntax, pointer handling
- Java: Check class scope, proper return types

**Issue: Taking too long per problem**
- Target: ~1-1.5 min per Easy, 2 min per Medium, 2.5 min per Hard
- Speed up: Use template above, copy/modify starter code
- Batch similar patterns: Do multiple Array problems in sequence
